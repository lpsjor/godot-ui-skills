# Skills

| Skill | Use it for |
|---|---|
| [godot-ui-from-concept](godot-ui-from-concept/SKILL.md) | Concept-to-Godot UI reconstruction with native containers and theme variations. |
| [godot-pixel-ui](godot-pixel-ui/SKILL.md) | Pixel fonts, CJK subsets, icon core centering, and 9-patch neon glow. |
| [higgsfield-game-ui](higgsfield-game-ui/SKILL.md) | Game UI icon sheets, sprites, and starfields with Higgsfield. |

Install from the repository root:

```bash
npx skills add . --list
npx skills add .
```
